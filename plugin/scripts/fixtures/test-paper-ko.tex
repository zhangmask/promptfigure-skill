\section{서론}
기존의 육안 검사는 비용이 높고 효율이 낮다. 자동화된 결함 검출 기법이 필요하다.
\section{검출 기법 설계}
본 기법은 2단계 아키텍처를 채택한다. 첫 단계에서 이미지 전처리와 증강을 수행하고, 다음 단계에서 결함 분류를 실행한다.
입자 군집 최적화로 주요 파라미터를 자동 탐색한다. 입자 군집 최적화는 전역 탐색에 유리하고 국소 해에 빠지기 어렵다.
데이터 증강 전략은 랜덤 크롭, 색상 지터, 탄성 변형을 포함한다.
\section{실험 결과 분석}
본 기법의 정확도는 91.3%에 도달하며 기준선을 2.4포인트 상회한다. 학습에는 50 에포크가 필요했다.
